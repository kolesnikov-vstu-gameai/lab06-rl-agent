## Пример выполнения

**Где это в играх.** AlphaStar (DeepMind) обыграл профессионалов в StarCraft II, OpenAI Five — чемпионов в Dota 2.
Sony AI обучила с подкреплением гонщика Gran Turismo Sophy, который обгоняет лучших игроков и при этом соблюдает правила
честной борьбы. Unity ML-Agents позволяет обучать агентов прямо в сцене Unity; студии применяют RL для ботов-тестировщиков
и соперников в гонках и спортивных играх.

**Зачем:** вместо того чтобы вручную прописывать каждое действие, задаётся цель (награда), и агент сам находит стратегию.
CartPole и LunarLander — минимальные среды, на которых видно весь цикл: MDP, обучение, кривые, сравнение алгоритмов.

**Пример заполненного MDP** (`docs/mdp.md`) для CartPole-v1:

- **Состояние S:** 4 числа: позиция и скорость тележки, угол и угловая скорость шеста.
- **Действия A:** 2 дискретных: толкнуть влево / вправо.
- **Награда R:** +1 за каждый шаг, пока шест не упал.
- **Переходы / горизонт:** эпизод заканчивается при угле > 12°, выезде за край или через 500 шагов.

**Порядок работы:**

```bash
python -m lab06.train --config configs/ppo.yaml     # ~2–5 мин на CPU
python -m lab06.train --config configs/dqn.yaml
python -m lab06.evaluate --algo ppo
python -m lab06.evaluate --algo dqn
python -m lab06.plot                                # results/learning_curves.png
```

**Пример таблицы результатов:**

| Алгоритм | Шагов обучения | Средняя награда (20 эп.) | Std | Время обучения |
|---|---|---|---|---|
| PPO | 100 000 | 487.3 | 21.4 | 3 мин |
| DQN | 100 000 | 312.8 | 104.6 | 4 мин |

**Пример вывода:** «PPO устойчиво выходит на 500 после ~60k шагов. DQN при тех же шагах не дотягивает до порога
и сильно колеблется. Увеличение `total_timesteps` до 200k подняло DQN до 465».
Любую смену гиперпараметров делайте в `configs/*.yaml` и фиксируйте в README, что поменяли и что это дало.
